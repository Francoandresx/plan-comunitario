# Plan comunitario Nueva Italia

Plan de acción de noviembre y diciembre de 2026 para el proyecto comunitario de Nueva Italia, Tahuanía, con RiverWind Perú.

Es una página estática: `index.html`, `styles.css` y `app.js`. Se publica con GitHub Pages desde la rama `main`.

Para probar otra fecha en la tarjeta "Lo que sigue", agrega `?hoy=AAAA-MM-DD` al enlace.
